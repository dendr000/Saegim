# 폭탄 돌리기 (Bomb Pass)

완료일: 2026-09-05

## 목표

CLAUDE.md "향후 추가" 목록의 5순위 게임. "타이머가 랜덤하게 터짐. 순서가
돌아오는 조마조마함이 실력과 무관하게 작동." 사용자가 추가로 짚은 두 가지:
(1) 학생 개인 기기 입력을 염두에 둘 것(보스 레이드 때와 동일한 요구),
(2) 시간제한 게임이라 교사가 매번 학생을 검색해서 고르는 방식은 안 맞고,
누구에게 터졌는지 화면에 보여야 한다.

## 설계 결정

- **참가자**: `ParticipantPicker` 재사용(개인/모둠 선택), 최소 2명 이상
  필요(`canStart`에 조건 추가).
- **턴은 원형으로 순환**(`(turnIndex+1) % turnOrder.length`) — 타임어택
  핫시트의 선형 진행과 다름. 정답이어야만 다음 사람에게 폭탄이 넘어가고,
  오답이면 같은 사람·같은 문제로 유지된다(동시 진행 모드의 "오답이면 문제
  유지"와 같은 결). 실력(빨리 넘길 수 있음)과 운(터지는 시점 자체는 숨겨져
  예측 불가)이 함께 작동하도록 설계 — CLAUDE.md "운과 전략의 개입은 의도된
  것" 원칙에 맞춘 선택.
- **활성 참가자가 항상 고정**(타임어택 핫시트와 같은 구조)이라 교사가 학생을
  검색해서 고를 필요가 없다 — `BombPassControls`는 `activeParticipantLabel`을
  그대로 표시하고, 판정 버튼만 누르면 된다. 사용자가 지적한 "교사가 일일이
  입력하기엔 시간제한 게임"이라는 문제를 검색 UI 자체를 없애는 방식으로
  해결했다.
- **숨겨진 폭탄 타이머**: 라운드마다 `[최소, 최대]` 초 범위에서 무작위 값을
  뽑아 `useCountdownTimer(durationSeconds, {resetKey, onExpire})`를 그대로
  재사용하되, `durationSeconds` 자체가 리듀서 상태(`currentRoundSeconds`)
  안에서 라운드마다 새로 뽑혀 바뀐다 — 훅 코드는 전혀 안 건드리고 인자만
  다르게 넘겼다. 화면엔 숫자를 표시하지 않는다(`TimerControls`는 버튼만
  있어 그대로 재사용 가능).
- **폭발 시**: 그 순간 폭탄을 든 참가자의 점수에서 고정 페널티를 차감(0
  밑으로는 안 내려가게 클램프)하고 콤보를 리셋, 폭탄은 다음 사람에게
  넘어간다(현재 미해결 문제는 버려짐 — 보스 레이드의 `SKIP_QUESTION`과 같은
  이유). **누구에게 터졌는지**(`state.lastExplosion`)는 다음 폭발이 있을
  때까지 화면에 지속 표시한다 — 사용자가 요구한 "터진 학생 표시".
- **문제 큐 소진 시 게임 종료**(타임어택 동시 진행/보스 레이드와 같은 이유,
  같은 문제 재활용으로 무한 점수 방지). 교사가 "게임 종료"로 언제든
  종료 가능, "폭탄 강제로 넘기기"로 문제가 애매할 때 점수 변동 없이
  스킵 가능.
- **점수 공식은 기존 것 재사용**: `timeAttack/scoring.ts`의
  `calculateScoreForCorrectAnswer` 그대로.
- **학생 개인 기기 대비**: `SUBMIT_ANSWER` 액션이 `Answer{participantId,
  value, submittedAt}` 객체 하나만 소비 — 누가/어떻게 답을 제출했는지
  리듀서가 몰라도 되는 기존 패턴을 그대로 따랐다. 실제 네트워킹은 v1
  범위 밖이라 만들지 않았다.

## 검증 결과

- `npm run typecheck` 통과.
- 리듀서를 `tsx`로 직접 실행(임시 export 후 삭제): 정답 시 원형으로 다음
  사람에게 넘어가는지(마지막 사람 다음은 처음으로), 오답 시 같은 사람·같은
  문제 유지 + 콤보 리셋, 폭발 시 페널티 적용(0 밑 클램프)·콤보 리셋·
  `bombHitCount` 증가·다음 사람으로 이동, 수동 패스/종료/점수 수정, 문제 큐
  소진 시 종료, 종료 후 액션 무시 — 총 27개 케이스 확인.
- 브라우저로(fixture mock 디버그 하네스) 실제 플레이: 폭발이 실제로 발생해
  "마지막으로 터진 사람"이 표시되는지, 숫자 타이머가 화면에 전혀 안
  보이는지, 정답 처리 시 점수 반영과 다음 사람으로 원형 이동, 폭탄 강제
  넘기기 동작, 문제 소진 시 결과 화면 도달. `window.sessions.save` 호출을
  가로채 실제 저장 payload를 확인 — `gameMode: "bombPass"`, 정확한
  `finalScores`, `answers`(판정된 답만 기록되고 폭발/수동패스는 안 남는 것도
  확인)까지 정상.
- 최종 `npm run dev`(Electron) 재부팅: 에러 없이 정상 기동 확인.
