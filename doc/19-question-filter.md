# 문항 필터: 시대/단원 체크박스 + 난이도 필터

완료일: 2026-09-05

## 배경

문제 빙고 작업 중 사용자가 지적: "난이도별 사용 가능한 개수라고 하는데, 난이도
1만 나오게 하거나 2, 3만 나오게 하거나 선택할 수 있어야 하지 않을까? 아니면
어느 시대의 문제만 나온다든가, 어느 나라의 문제만 나온다든가. 인물 관련
문제라든가... 다른 게임도 그렇고 그런 기능은 없는 것 같더라."

기존 7개 게임 설정 화면 중 5개는 시대/단원을 자유 텍스트 입력(부분 문자열
포함 매칭)으로만 걸렀고, 난이도 필터는 어디에도 없었다. 땅따먹기는 그마저도
없었다(지역-태그 매칭만 존재).

## 설계 결정 (AskUserQuestion으로 확인)

- **시대/단원: 자유 텍스트 → 실제 값 목록에서 체크박스로 고르기.** 오타·부분
  일치로 인한 의도치 않은 매칭을 없애고, 지금 문제은행에 실제로 어떤 시대/단원
  값이 있는지 목록으로 바로 보여준다.
- **난이도 필터: 전 게임에 추가.**
- **"인물 관련 문제" 같은 주제 분류: 새 스키마 필드를 만들지 않는다.** 교사가
  기존 `unit`(단원) 필드에 "인물"처럼 주제성 값을 직접 적어 넣으면, 새로 만든
  단원 체크박스 목록에 자연스럽게 나타난다 — CSV/CRUD/문항 스키마를 전혀
  건드리지 않고 요구를 충족.

## 한 일

- `games/_shared/QuestionFilterPicker.tsx`(신규): `QuestionFilterState{eras,
  units, difficulties}`(모두 `Set`), `createEmptyQuestionFilter()`,
  `applyQuestionFilter(questions, filter)`(각 목록이 비어있으면 "필터 없음"으로
  취급 — 기존 빈 문자열 자유 텍스트 필터와 같은 기본 동작), 그리고 실제
  컴포넌트: 넘겨받은 문제 목록에서 시대/단원 값을 중복 제거·정렬해 체크박스로
  렌더링 + 난이도(1/2/3) 체크박스는 항상 표시.
- 7개 게임 설정 화면 전부에 적용:
  - `timeAttack/TimeAttackSetup.tsx`, `initialLetter/InitialLetterSetup.tsx`,
    `hintDeduction/HintDeductionSetup.tsx`, `bossRaid/BossRaidSetup.tsx`,
    `betting/BettingSetup.tsx` — 기존 자유 텍스트 두 입력을
    `QuestionFilterPicker` 하나로 교체. 각 파일은 먼저 문항 **유형**으로
    걸러진 풀(`typeSupportedQuestions`)을 만들고, 그 위에
    `applyQuestionFilter`를 적용해 `eligibleQuestions`를 얻는 동일한 2단계
    패턴을 따른다.
  - `territory/TerritorySetup.tsx` — 기존엔 필터가 아예 없었다(유형만 거른
    `supportedQuestions`를 지역 매칭에 바로 넘김). `QuestionFilterPicker`를
    유형 필터와 지역 매칭 사이에 끼워 넣는 새 통합.
  - `questionBingo/QuestionBingoSetup.tsx` — 기존 자유 텍스트 필터를 교체하되,
    이미 있던 "난이도별 사용 가능한 문제 수" 안내 목록은 그대로 유지(필터
    적용된 `eligibleQuestions` 기준으로 재계산되도록만 연결) — 이 안내는
    빙고 격자 칸의 난이도별 매칭 가능 여부를 보여주는 용도라 필터와는 다른
    관심사.

## 검증 결과

- `applyQuestionFilter`를 `tsx`로 직접 실행: 빈 필터(전체 통과), 시대만/단원만/
  난이도만 필터, 복합 필터(AND 결합) 5개 케이스 확인.
- `npm run typecheck` 통과.
- 브라우저로(fixture mock 디버그 하네스, 5개 문항·3개 시대·4개 단원·3개 난이도로
  구성) 확인:
  - 타임어택: 시대 체크(조선후기) 5→2개, 난이도 체크(1) 추가 시 2→1개(정확히
    조선후기+난이도1 문항 하나)로 AND 결합 확인.
  - 초성 퀴즈: 단답형만 필터링된 후보 풀에서 단원 체크박스 목록에 객관식만
    있는 "백제" 단원이 안 뜨는지 확인(유형 필터가 먼저 적용된 뒤 그 풀에서
    옵션을 뽑는다는 것의 증거).
  - 땅따먹기: 학급 선택 후 필터 체크박스 토글 시 에러 없이 동작(지역 매칭 로직
    자체는 이번에 안 건드림 — 목 SVG가 실제 지도 규격이 아니라 지역 카운트
    표시 자체는 검증 범위 밖).
  - 문제 빙고: 기존 "난이도별 사용 가능한 문제 수" 목록이 필터 적용 후에도
    정확한 값(난이도1: 2개, 2: 2개, 3: 1개)으로 남아있는지 확인.
  - 힌트 차감형/보스 레이드/베팅형은 타임어택과 완전히 같은 통합 패턴이라
    별도 브라우저 확인 없이 typecheck 통과로 갈음.
- 최종 `npm run dev`(Electron) 재부팅: 에러 없이 정상 기동 확인.
