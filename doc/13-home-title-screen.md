# 홈 화면(타이틀 스크린) 리디자인

완료일: 2026-09-04

## 목표

기능 구현은 계획대로 우선순위를 이어가되, 그 전에 "시작 페이지"(홈 화면)를 실제
역사 게임 타이틀 화면처럼 다듬어달라는 요청. 애니메이션·클릭 모션 포함, 나중에
설정 버튼이 들어갈 것도 감안, SVG/이미지 활용 가능.

## 설계 결정

- **기존 상아색·남색 팔레트를 그대로 쓰되, 홈 화면만 "타이틀 스크린"답게 격을
  높였다.** 색 자체를 새로 정하지 않고(이미 합의된 팔레트), 장식·모션만 추가.
- **격자(lattice) 배경 패턴**: 한지 창살문을 연상시키는 옅은 격자 무늬를 순수
  CSS(`repeating` 없이 두 방향 `linear-gradient` 겹침)로 구현 — 이미지 파일 없이
  텍스처 효과.
- **네 귀퉁이 액자 장식**: SVG 코너 브래킷 하나를 그려서 `transform: scaleX/scaleY`로
  4방향 재사용 — 옛 서책·액자 느낌.
- **입장 애니메이션**: 제목 → 구분선 → 부제 → 메뉴 타일 4개가 순서대로 페이드인
  (각각 `animation-delay`로 스태거).
- **메뉴를 아이콘 타일로 전환**: 기존 텍스트 버튼 4개를 아이콘+라벨이 있는 카드형
  타일로 바꿨다. 호버 시 살짝 떠오르며 그림자 커짐, 클릭 시 눌리는 모션. "게임 시작"
  타일만 남색으로 강조하고 은은하게 맥동하는 그림자 애니메이션(`home-pulse-glow`)을
  줘서 시선을 끌게 했다.
- **아이콘은 라이브러리 없이 직접 그린 인라인 SVG**(책/사람/재생버튼/시계) — 새
  의존성 추가 없이 일관된 스타일(같은 stroke-width) 유지.
- **설정 버튼 자리**: 실제 빈 placeholder 엘리먼트는 넣지 않았다(쓰이지 않는 DOM은
  안 만드는 게 낫다고 판단). 대신 제목이 중앙 정렬돼 있고 코너 장식이 안쪽으로
  22px 들어와 있어서, 나중에 우상단에 톱니바퀴 아이콘 버튼을 추가해도 지금 레이아웃을
  다시 짤 필요가 없다.
- **마스코트 이미지**: 사용자가 보내준 캐릭터 이미지(전통 의상을 입은 3D 캐릭터)는
  아직 파일로 전달받지 않아 반영하지 않았다. 배경이 있는 스튜디오 사진이라, 여기서
  코드로 배경을 지우면 머리카락·그림자 경계가 지저분해질 수 있어 사용자가 직접
  누끼(투명 배경 PNG)를 따서 주는 걸 권장함. 받으면 제목 옆이나 타일 위쪽에 자리를
  잡아 넣을 예정 — 지금 레이아웃은 이미지 추가 시 재작업이 크게 필요 없는 구조.

## 한 일

- `src/renderer/src/pages/Home/Home.tsx` — 전면 재작성: 코너 장식 4개, 제목/구분선/
  부제, 아이콘 4종(책/사람/재생버튼/시계) 인라인 SVG 컴포넌트, 아이콘 타일 메뉴.
  네비게이션 로직(각 버튼의 `onClick`)은 그대로.
- `src/renderer/src/styles/global.css` — `.home*` 클래스 한 벌 추가(약 200줄):
  격자 배경, 코너 장식, 타이틀/구분선/부제 애니메이션, 타일 그리드·호버·눌림·
  강조(pulse-glow) 애니메이션. 기존 관리/게임 화면 스타일은 건드리지 않음.

## 검증 결과

- `npm run typecheck` 통과.
- 브라우저로 확인: 코너 장식·격자 배경·입장 애니메이션 스크린샷 확인, 타일 호버 시
  들뜨는 효과 확인, `getComputedStyle`로 "게임 시작" 타일의 `box-shadow`가 실제로
  주기적으로 바뀌는(맥동) 것을 수치로 확인.
- 메뉴 그리드가 좁은 컨테이너에서 1열로 정상적으로 접히는 것을 컨테이너 폭을 직접
  좁혀서 확인(반응형 정상 동작).
- 클릭 시 실제 네비게이션(게임 시작 → 게임 선택 화면)이 그대로 동작하는 것 확인 —
  로직은 안 건드렸으니 당연하지만 재확인.
- 최종 `npm run dev`(Electron)로 재부팅 확인.
