# 게임 선택 화면 리디자인 (검색 + 카드형 + 카테고리)

완료일: 2026-09-04

## 목표

홈 화면 리디자인에 이어 게임 선택 화면도 다듬어달라는 요청. 특히 CLAUDE.md
"향후 추가" 목록대로 게임 모드가 계속 늘어날 걸 감안해서, 단순 버튼 나열이 아니라
검색·분류가 되는 구조로 만들어달라는 요구. 이모지·기호 문자는 쓰지 않고 SVG로.

## 설계 결정

- **게임 모드 메타데이터를 데이터로 분리했다** —
  [gameModeCatalog.tsx](../src/renderer/src/pages/GameSelect/gameModeCatalog.tsx)에
  `{id, title, description, category, icon}` 목록을 두고, 화면은 이 배열을 렌더링만
  한다. 나중에 게임 모드가 추가되면(힌트 차감형, 보스 레이드 등) 이 배열에 항목 하나
  추가하는 것만으로 검색·분류·카드 UI에 전부 자동 반영된다 — 화면 컴포넌트를 다시
  손댈 필요가 없는 구조.
- **CLAUDE.md에 이미 있는 분류(개인전/전체 참여형, 팀 대항형, 개념 학습형)를 그대로
  카테고리로 썼다** — 새 분류 체계를 만들지 않고 기존 문서와 맞춘 것.
- **검색은 제목+설명 텍스트에 대해 부분 일치**(대소문자 무시) — 문제은행/학급관리 등
  기존 화면의 검색 패턴과 동일한 방식. 검색 결과가 없는 카테고리 섹션은 통째로
  숨긴다.
- **이모지·유니코드 기호 문자를 전혀 쓰지 않았다.** 뒤로가기 화살표(`←`)와 돋보기도
  전부 직접 그린 인라인 SVG로 교체 — 새 아이콘 4종(초시계/지도/동전더미/말풍선)과
  같은 스타일(24×24 뷰박스, 동일 stroke-width)로 통일.
- 카드는 홈 화면 타일과 같은 시각 언어(그림자·호버 시 살짝 뜨는 모션·클릭 시 눌림)를
  쓰되, 클래스는 별도로(`mode-*`) 둬서 화면별 스타일이 서로 얽히지 않게 했다.

  뒤로가기 화살표·검색 아이콘 SVG 추가. 카드 클릭 시 기존과 동일하게 각 모드의

- `styles/global.css` — `.icon-button`(아이콘+텍스트 버튼 공통), `.mode-search`,

  홈 화면의 `home-fade-in-up` 애니메이션을 그대로 재사용(카드 입장 효과).

## 검증 결과

- `npm run typecheck` 통과.
- 브라우저로 확인(fixture mock 디버그 하네스): 카테고리별로 카드가 정상 렌더링,
  검색어 입력 시 제목/설명 부분 일치로 필터링되고 빈 카테고리는 숨겨지는 것 확인,
  일치하는 게임이 없을 때 안내 문구 확인, 검색어를 지우면 전체 목록 복원 확인,
  카드 클릭 시 실제로 해당 게임의 설정 화면으로 이동하는 것 확인(초성 퀴즈로 검증),
  뒤로가기 버튼(게임 선택→홈)도 정상 동작 확인.
- 최종 `npm run dev`(Electron)로 재부팅 확인.
