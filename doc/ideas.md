# 아이디어 노트

당장 구현하지 않고, 나중에 검토·시도해볼 아이디어를 여기 정리해둔다.
`CLAUDE.md`의 구현 순서/절대 규칙에 속한 확정 사항이 아니라, 아직 설계가 덜 된 제안 단계.

## 땅따먹기 — 격자 변형 두 가지 (2026-09-04 제안)

현재 땅따먹기는 SVG 지도(`data/maps/`)의 실제 지역 칸을 쓰는 방식 하나뿐이다.
여기에 더해, SVG 지도 대신 **추상 격자**를 쓰는 모드를 새로 추가하자는 아이디어.
(CLAUDE.md의 "향후 추가 > 팀 대항형 > 땅따먹기: 5×5 격자 중 원하는 칸을 골라 문제 풀고
점령. 세 줄 만들면 보너스"와 맞닿아 있음.)

### 방식 A — 자유 크기 + 시대별 랜덤 배치

- 격자 크기를 시작 전에 자유롭게 선택 (예: 5×5, 6×6, 8×10 등 — 정사각形에 한정하지 않음).
- 시작 전에 이번 판에 쓸 시대(예: 고구려, 신라, 백제…)를 여러 개 고른다.
- 격자의 각 칸에 고른 시대 중 하나를 랜덤 배정 — 그 칸을 선택하면 배정된 시대로
  태깅된 문제만 나온다 (현재 지도 모드의 `regionQuestionMatch.ts` 매칭 로직을 그대로
  재사용 가능해 보임 — 지역 label 대신 칸에 배정된 시대명으로 매칭).
- 지도 SVG 자산이 없어도 바로 쓸 수 있는 게 장점 — 새 단원을 지도 없이도 빠르게
  게임화할 수 있음.

### 방식 B — 홀수 격자 + 빙고 보너스

- 격자를 홀수 크기로 한정 (5×5, 7×7, 9×9…) — 가로/세로/대각선에 명확한 "한 줄"이
  존재하게 하기 위함으로 보임.
- 한 팀이 가로/세로/대각선 한 줄을 전부 점령하면 추가 점수(보너스) 지급.
- CLAUDE.md의 "향후 추가" 목록에 있는 "문제 빙고"(난이도를 칸에 미리 배치)와도
  결합 여지가 있음 — 아직 미정.

### 미정 사항 (나중에 설계 단계에서 정할 것)

- 두 방식이 서로 다른 게임 모드(폴더)인지, 아니면 기존 `territory` 모드의 옵션인지.
- 방식 A에서 격자가 정사각형이 아닐 때(8×10 등) 대각선/줄 개념이 있는지, 아니면
  방식 B(홀수 정사각)에만 줄 보너스가 적용되는지.
- 격자 모드에서 SVG 지도 렌더링(`MapView.tsx`, event delegation 클릭 처리)을 그대로
  재사용할지, 격자 전용 컴포넌트를 새로 만들지.
- 시대별 랜덤 배치 시, 선택한 시대 수보다 격자 칸 수가 훨씬 많을 때 같은 시대가
  반복 배정되는 게 자연스러운지(문제 태그가 부족하면 `blockedRegionId`처럼 막을지).
