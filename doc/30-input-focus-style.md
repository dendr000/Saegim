# 입력창 포커스 스타일 통일 + 학급 이름 플레이스홀더 정리

완료일: 2026-09-05

## 배경

학급 관리 CSS 개편 직후 실제 exe로 확인하던 중 사용자가 지적: 학급 이름
입력창에 포커스를 주면 테두리가 도드라진 색(OS 테마 색이 그대로 새어
들어온 기본 포커스 링)으로 바뀌어 "위화감"이 있었다. `global.css`에
`input`/`select`/`textarea`의 `:focus` 스타일을 따로 정의한 적이 없어서,
브라우저(Electron/Chromium)가 시스템 접근성 설정에 따라 자체 색상의
포커스 링을 그려 넣고 있었던 것 — 상아색·남색 팔레트와 전혀 안 어울리는
색이 튀어나온 원인이다.

이건 학급 관리만의 문제가 아니라 **앱 전체 모든 입력창**(문제은행 폼,
게임 설정 화면, 게임 진행 중 숫자 입력 등)에 똑같이 있던 문제라 전역으로
고쳤다.

## 한 일

- `styles/global.css`: 관리 화면(`input, select, textarea`)과 게임 화면
  (`.stage input, .stage select`) 양쪆에 `outline: none` + 팔레트에 맞춘
  `:focus` 스타일(테두리를 `--color-primary`/`--stage-primary`로, 은은한
  남색 글로우 `box-shadow`)을 추가했다. OS/브라우저 기본 포커스 링을
  완전히 대체해서, 어떤 환경에서 켜도 항상 같은 색으로 보인다.
- `ClassManager.tsx`: 학급 이름 입력창의 플레이스홀더에서 `"(예: 1학년
  3반)"` 예시 문구를 지우고 `"학급 이름"`만 남겼다.

## 검증 결과

- `npm run typecheck` 통과.
- 브라우저로(fixture mock 디버그 하네스) 실제 확인: 학급 이름 입력창을
  클릭했을 때 테두리가 남색 계열로 부드럽게 바뀌고 은은한 글로우가
  생기는지(스크린샷으로 확인), 플레이스홀더가 "학급 이름"으로만 보이는지.
- 최종 `npm run dev`(Electron) 재부팅: 에러 없이 정상 기동 확인.

## 참고 — exe와 소스 코드 동기화

이 세션에서 두 번 연속으로 "exe를 실행했는데 최신 변경이 안 보인다"는
지적이 있었다. 원인은 매번 같았다 — `dist/saegim.exe`는 `npm run
build:win`을 수동으로 다시 돌려야만 갱신되고, `npm run dev`로 확인하는
개발 흐름과는 완전히 분리돼 있다. 앞으로 CSS/기능 변경 후 사용자가 실제
exe로 확인하려 할 걸 예상되면, 먼저 재빌드해서 최신 상태로 맞춰두는 편이
낫다.
